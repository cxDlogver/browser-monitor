# Changelog

## 0.1.0 — 2026-10-13

- First public npm release; install globally and run `bm` from any business directory.
- Session login, status and logout; project list, creation, detail and local context selection.
- Read and replace business Origins; export SDK JSON and client initialization examples.
- Bounded event search and cursor pagination, retained data summary, event processing diagnostics, queue status and bounded waiting.
- JSON output by default, table formatting, fixed error codes and exit codes, health checks and output limits.
- The published package includes prebuilt JavaScript and uses Node.js built-in modules only. Node.js 22 or newer is required.
- Data diagnostics require the matching platform APIs and the `0007_diagnostics.sql` migration. Installing the CLI does not install or start the monitoring platform.
